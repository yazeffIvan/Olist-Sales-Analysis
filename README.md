# Анализ продаж бразильского маркетплейса Olist
Pet-проект | Data Analysis | Power BI + SQL + Python
## О проекте
Анализ данных одного из крупнейших маркетплейсов Бразилии — Olist.  
Цель проекта — выявить ключевые бизнес-инсайты, найти точки роста и предложить конкретные рекомендации по увеличению выручки и улучшению клиентского опыта.
## Используемые технологии
- SQL Server — сбор и анализ данных
- Python (pandas, seaborn, matplotlib) — EDA и визуализации
- Power BI — интерактивные дашборды
- DAX — бизнес-метрики и расчеты
## Основные метрики проекта
- Общая выручка: 16,01 млн BRL
- Количество заказов: 99 тыс.
- Средний чек: 160,99 BRL
- Средняя задержка доставки: 9 дней
- Доля положительных отзывов: 77,07%
## Ключевые инсайты
- Категория Electronics является главным драйвером выручки.
- Штат SP (São Paulo) сильно доминирует по продажам.
- Задержки доставки остаются значительной проблемой, особенно в штатах SP и MG.
- Уровень повторных покупок относительно низкий.
- Выручка имеет ярко выраженную сезонность с пиком в марте-мае.
## Рекомендации для бизнеса
Короткосрочные:
- Усилить контроль логистики в ключевых штатах для снижения задержек.
- Запустить программу лояльности для повышения повторных покупок.
- Увеличить маркетинговый бюджет на категорию Electronics.
Среднесрочные:
- Провести ABC-анализ товаров и оптимизировать ассортимент.
- Разработать региональные стратегии развития для штатов с низкой текущей выручкой.
## Структура проекта
- `SQL/` — все запросы для расчёта метрик
- `Python/` — код для EDA, визуализаций и расчётов
- `Power BI/` — дашборды (файл .pbix + скриншоты)
- `reccomendations` — файл с ключевыми выводами и рекомендациями
- `data/` — исходные данные
